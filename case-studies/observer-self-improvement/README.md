# Observer self-improvement: ten cycles

This folder records ten cycles, run from 21 to 23 October 2026, in which the observer-multi-lens-reasoning skill mapped its own process, critiqued that process with its own method and revised itself. A blind test checked the revisions in seven of the cycles, and the final version was also checked on a held-out text. Every agent was Opus 5.5.

Start with FINAL-SUMMARY.md. It gives the versions, the scores by cycle and effort, the held-out result, a recommendation and the final SKILL.md. That final version, 1.10, is published as the skill in .claude/skills/observer-multi-lens-reasoning/. In the author's local copy, this folder sits inside the skill's folder as self-improvement/, which is the location PROTOCOL.md describes.

## Files

| File | What it holds |
|---|---|
| FINAL-SUMMARY.md | The results of all ten cycles, the recommendation and the final SKILL.md |
| PROTOCOL.md | How each cycle ran: the agents and their effort, the test, the keep rule and the limits |
| scoring-rubric.md | The criteria for scoring each test against the blind review's findings |
| cycle-01/ to cycle-10/ | Each cycle's candidate SKILL.md, its changes with a diff, the improver's self-analysis, the test outputs, the score files and the report |

The test paper is 03-enhanced-paper.md and the held-out text is 01-agent-draft.md, both in ../ai-authority-sensitive-decisions/. The findings used for scoring come from 05-blind-review.md in that folder.

## Limits

There was one test paper and one held-out text, both on the same subject. Each version ran once per cycle, one scorer scored each run, and every agent was a Claude model. FINAL-SUMMARY.md sets out these limits and what they mean for the results.
